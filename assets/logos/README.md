# StreamLive — logos des chaînes

Les logos de **Chaînes & Apps** utilisent la convention :

`assets/logos/<id>.png`

Le champ `id` de chaque chaîne correspond directement au nom du fichier PNG.

Exemples :
- `rti-1.png`
- `rti-2.png`
- `nci.png`
- `a-plus-ivoire.png`
- `emci-tv.png`
- `esperance-tv.png`
- `france-24.png`
- `telemundo.png`

Le catalogue affiche automatiquement les **initiales** lorsque le PNG n'est pas encore présent. Lorsqu'un logo autorisé est ajouté au chemin attendu, il remplace automatiquement le fallback.

Utiliser uniquement des visuels dont StreamLive dispose des droits ou de l'autorisation nécessaire.
